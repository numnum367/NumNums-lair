# 🦊 NumNums-lair

Welcome to my den! This is my personal portfolio website — a little corner of the internet where I show off projects, share a bit about myself, and keep things fun.

## ✨ About

NumNums-lair is a simple, static personal portfolio site. It's built to be lightweight, easy to update, and easy to host anywhere (GitHub Pages, Netlify, Vercel, you name it).

## 🗂️ Structure

```
NumNums-lair/
├── index.html          # Homepage
├── assets/
│   ├── style.css        # Styling
│   ├── script.js         # Any interactivity
│   └── numnum-avatar.png # Site mascot / logo (add your own!)
├── .github/
│   └── workflows/        # CI/deploy automation
├── CONTRIBUTING.md
├── CHANGELOG.md
├── LICENSE
└── README.md
```

## 🚀 Getting started

Just open `index.html` in a browser — no build step needed.

To deploy on GitHub Pages:
1. Go to **Settings → Pages**
2. Set the source branch to `main` and folder to `/ (root)`
3. Save, and your site will be live at `https://numnum367.github.io/NumNums-lair/`
