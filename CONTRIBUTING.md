# Contributing to NumNums-lair 🦊

This is a personal portfolio site, so contributions are mostly for fun, feedback, or bug fixes rather than active feature development. Still, you're welcome in the lair!

## Rules of the lair

1. **Be respectful** — keep feedback constructive and kind.
2. **Open an issue first** for anything beyond a typo fix, so we can chat before you spend time coding.
3. **Keep it lightweight** — this site intentionally has no build step or heavy dependencies. Please try to keep it that way.
4. **Test locally** — just open `index.html` in a browser to check your changes before opening a PR.

## Making a change

1. Fork the repo
2. Create a branch: `git checkout -b fix/something`
3. Make your changes
4. Commit: `git commit -m "Fix: description of change"`
5. Push and open a Pull Request

Thanks for stopping by the lair! 🐾
